# 進度予定表システム（鳴海中用 / 学校共通用）

中学校教諭用の週単位の進度予定表（Excel マクロ有効ブック）。鳴海中用と、学校共通用の 2 種類があります。

## ファイル

| パス | 説明 |
|---|---|
| `進度予定表システム_鳴海.xlsm` | 鳴海中用・最新版（記入データは消去済み。第01〜16週の空シートあり） |
| `進度予定表システム_共通.xlsm` | 学校共通用・最新版（週シートなしの配布用テンプレート） |
| `vba/` | 鳴海用の VBA ソース（テキスト・Source of truth） |
| `vba-共通/` | 学校共通用の VBA ソース（同上） |
| `進度予定表システム_鳴海.xlsm.backup` | 鳴海中用・一番最初のオリジナル |
| `進度予定表システム_鳴海.xlsm.before_test_feature` | 鳴海中用・テスト機能追加前のバージョン |
| `scripts/` | xlsm の VBA を抜き出す / 書き戻す Python ツール |
| `CLAUDE.md` | Claude (CLI / Web 版) 向け作業ガイド |
| `SETUP_WEB.md` | Web 版 Claude Code セットアップ手順 |

`vba/` と `vba-共通/` は、それぞれ対応する `.xlsm` から抜き出したものです。
`build_vba.py` で組み立て直して再度取り出すと、元のソースと完全に一致することを確認しています
（`.xlsm` 自体は VBA のコンパイルキャッシュを毎回ゼロクリアするため、バイト一致はしません）。

## 実装済みの機能

### 基本設定シートのボタン（6 つ・`Auto_Open` で毎回貼り直し）

| ボタン | 動作 |
|---|---|
| 新しい週を追加 | 週案_テンプレートを複製して「第NN週」シートを作り、日付を入れる |
| 1・2・3 学期 PDF 出力 | 該当学期の週シートをまとめて PDF に出力 |
| 次年度ファイルを作成 | 年度を進めた新しいブックを別名保存 |
| 別ファイルからインポート | 別の `.xlsm` を選び、時間割マスターと第NN週シートを取り込む |
| 全データ消去（共通版のみ） | 週シートを全削除し、基本設定と時間割マスターを空に戻す |

「設定を完了」ボタンは基本設定シート上に配置され、時間割マスター・週案_テンプレート・
集計表を一括生成してからシートを保護します。

### 週シートの入力支援

- **授業の自動転記** — 時数欄に `月3` のように入れると、時間割マスターから科目名を隣のセルへ転記する（`Workbook_SheetChange`）
- **テスト機能** — 基本設定 B14 の「テスト」を選ぶと対象クラスを聞くダイアログが出る。
  セルには `テスト[,2-1,3-5,]` 形式で記録し、表示は `;;;"テスト"` 書式で「テスト」とだけ見せる。
  集計は `COUNTIF(範囲, "*,"&クラス名&",*")` で、選んだクラスだけ +1 される
- **総合の集計** — 集計欄のループを col=15 まで拡張
- **累計の範囲制限** — 現在シートの週番号以下のシートだけを合算
- **長期休業の自動スキップ** — 基本設定 B38:B43 に夏・冬・春休みの開始／終了（`7/18` 形式）を入れておくと、
  「新しい週を追加」が休業期間内の週を飛ばして次の登校日から始める（`休業スキップ調整`）

### 記入データについて

リポジトリに置いてあるのは**中身を空にした状態**です。基本設定・時間割マスター・
第01〜16週シートの入力値はすべて消してあります。使うときは基本設定を埋めて
「設定を完了」から始めてください。

第01〜16週のシート自体は残してあります。VBA のドキュメントモジュール
（`Sheet4`〜`Sheet19`）とシートが一対一で対応しており、シートだけ消すと
対応が崩れるためです。不要なら Excel 上で削除してください。

### 学校共通版だけの機能

- **学活カウント方式** — 基本設定 B4 で「特活に含める / 学活で独立」を選択。
  `集計補正` がこの値を見て、学活を特活に合算するか独立した項目として数えるかを切り替える。
  B4 を変更すると `学活方式チェンジ処理` が走り、集計表を組み直す
- **全データ消去** — 配布したテンプレートを使い回すためのリセット。週シートを全部消し、
  基本設定・時間割マスターの入力を空に戻す（確認ダイアログあり・元に戻せない）

## 編集ワークフロー

VBA を直すときは、必ず `.xlsm` から取り出して → テキストを直して → 書き戻します。

```bash
# 鳴海用
python3 scripts/extract_vba.py 進度予定表システム_鳴海.xlsm vba
#   vba/Module1.bas などを編集
python3 scripts/build_vba.py vba

# 学校共通用
python3 scripts/extract_vba.py 進度予定表システム_共通.xlsm vba-共通
#   vba-共通/Module1.bas などを編集
python3 scripts/build_vba.py vba-共通
```

引数を省くと鳴海用（`vba/`）が対象になります。
書き戻し先の `.xlsm` は `<ソースディレクトリ>/_meta.json` に記録されているので、
取り違えて別のブックを上書きすることはありません。

```bash
git add 進度予定表システム_鳴海.xlsm vba/
git commit -m "..."
git push
```

詳細は `CLAUDE.md` と `scripts/README.md` を参照。
